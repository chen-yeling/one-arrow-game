# 一箭又一箭

## 1. 项目名称

**一箭又一箭（One Arrow）**

## 2. 游戏简介

《一箭又一箭》是一款使用 Python 和 Pygame 开发的益智小游戏。

游戏中，棋盘上会出现多个不同方向的箭头。玩家需要判断箭头前方是否存在其他箭头或障碍物，并选择合适的箭头进行移动。

如果箭头前方没有阻挡，点击箭头后，箭头会沿指向方向飞出棋盘并消失；如果前方存在阻挡，则会触发碰撞反馈。玩家需要合理选择箭头的移动顺序，在规定的失误次数内完成关卡。

游戏包含多个关卡，随着关卡推进，棋盘布局和箭头排列会发生变化，增加游戏的挑战性。

## 3. 开发环境

- 操作系统：Windows
- 编程语言：Python 3.12
- 游戏开发框架：Pygame 2.6.1
- 开发工具：Visual Studio Code
- 项目运行方式：Python 命令行

## 4. 安装和运行方法

### 4.1 安装 Python

请先安装 Python 3.12 或其他兼容版本，并确保 Python 已添加到系统环境变量。

可以在命令行中输入：

```bash
python --version
```

如果能够正常显示 Python 版本号，说明 Python 安装成功。

### 4.2 安装 Pygame

打开命令行，进入项目所在目录，执行：

```bash
pip install -r requirements.txt
```

如果没有使用 `requirements.txt`，也可以直接安装 Pygame：

```bash
pip install pygame
```

### 4.3 运行游戏

进入项目目录后执行：

```bash
python one_arrow_game_collision_fixed_v4.py
```

也可以在 Windows 环境下使用：

```bash
py one_arrow_game_collision_fixed_v4.py
```

运行成功后即可进入游戏。

## 5. 游戏操作说明

### 鼠标操作

- **鼠标左键点击箭头**：选择并尝试移动该箭头。
- **前方没有阻挡**：箭头沿指向方向飞出棋盘并消失。
- **前方存在阻挡**：箭头与前方物体发生碰撞，并触发碰撞反馈。
- **点击错误箭头**：根据游戏规则扣除相应的失误次数。
- **完成当前关卡**：进入下一关。
- **达到失误次数上限**：游戏结束。

### 游戏目标

在有限的失误次数内，按照合理的顺序移动棋盘上的箭头，使所有需要消除的箭头完成移动，从而通过关卡。
